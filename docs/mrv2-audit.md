## 初学者的阅读路径

1. 总框架先理解三类对象：Token 行、逻辑专家、物理副本/本地槽位。
2. 部署与加载回答“专家在哪”；批次上下文回答“本批选择什么协议”。
3. MoE 前向先看 Runner 与 shared/routed 两支，再展开路由主线。
4. 路由主线继续展开 Router 与专家通信，分别追踪 ID 转换和张量流转。
5. 最后读 EPLB：采样窗口 → 策略 → 后台迁移 → 前台提交 → 后续前向使用新表。

每个节点提供原理、步骤、具体小例子、公式/符号、源码阅读提示和固定行号。教学 EP2 / E=8 / Top-2 不是实际部署参数；SwiGLU 公式是常见激活示例，不代表所有 MoE 使用相同激活。
